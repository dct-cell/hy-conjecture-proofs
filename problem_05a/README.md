# Problem 5a: Group-ring global dimension

[Problem](problem.md) · [HY result](hy_result.md) · [Original paper](https://www.mat.uniroma3.it/users/fontana/documents/CahenFontanaFrischGlaz_OpenProblemsArticle%20%282%29.pdf)

A counterexample to determination of group-ring global dimension from the base ring's global dimension and the group's isomorphism type. The torsion-order invertibility condition is retained.
